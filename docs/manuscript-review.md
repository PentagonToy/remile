# Manuscript review

Make room for the questions a careful reader might ask.

## Review a draft

1. Open Review in a LaTeX or Overleaf project.
2. Choose the provider and the file.
3. Select **Review file**.

Review returns source-linked questions. It does not edit the manuscript. Follow an excerpt to reconsider a claim, comparison or explanation in its own context.

## Return to a question

Saved questions remain when you move around the project. New reviews keep earlier questions. A changed source is marked so an older question does not appear to describe a fresh draft.

Export the questions as Markdown or JSON when you want to share them. Clear removes the project's saved reviews.

## Keep the scope in mind

Review reads the supplied source. It does not search the web, inspect figure pixels or verify cited papers. Treat its questions as prompts for judgement, not a verdict on the work.
