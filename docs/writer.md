# Writer

A letter, a cover note, a page you want to send. Writer keeps short documents simple.

## Begin a page

1. Choose Writer from Home.
2. Write on the page and use the left inspector to format your selection.
3. Save as DOCX, or export a PDF when the layout is ready.

## Shape the document

Text controls the font, size and colour. Paragraph holds alignment, line spacing and lists.

Insert a line, rectangle, image, table or LaTeX equation. Double-click a rectangle or table cell to write inside it. Drag objects into place. Hold Shift to keep a line horizontal or vertical.

## Set the page

Choose one or two columns in the toolbar. Settings at the bottom of the inspector opens paper size, orientation, headers, footers, page numbers and rulers.

Use Fit to bring the page into view. Lock position keeps an object in place. Text wrap lets the body flow around it.

## Save for later

DOCX keeps the document editable in Writer. PDF preserves its page layout. Opening an external Word document may simplify or reject unsupported layouts, so keep the original.
