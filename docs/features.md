# Features

## Documents

Home opens PDF and Markdown documents or a local LaTeX project. Recent entries carry TeX, MD or PDF badges. Clear recent entries through the recent-items menu. The sidebar displays the application version.

Convert images, Word and Markdown to PDF. Compress PDFs with colour and quality controls, compare the result and save a separate PDF. Combine PDFs in the chosen page order. Combine Markdown files by appending their sources in the chosen order and save as `.md`. The combination window accepts one format at a time.

## PDF

Switch between one-page and two-page views with the layout button. Two-page view pairs pages from the beginning: 1–2, 3–4 and so on. Enter a page number to navigate directly.

The sidebar provides pages, outline, search, highlights and comments. Select text to copy, highlight, annotate or translate. Scan & OCR recognises text with Apple Vision. Edit PDF provides text, annotation and page controls. Undo reverses editing operations; Save writes the document.

## Markdown

Read, Edit and Split share one source buffer. Outline folds above the brand footer. Editor settings control line numbers, source font size, spelling and live preview. Preview zoom adjusts the rendered document independently.

Maths completion provides TeX commands and environment blocks. Tab accepts a candidate; Escape dismisses it. Spelling and grammar suggestions exclude source syntax and formulae. Select a suggestion to locate or replace the text.

Format provides inline styles, links, lists, maths, code and table editing. Spreadsheet paste creates a Markdown table. Paste as Markdown retains bold, italic and links from formatted clipboard text. Pasting a URL over selected text creates a link. Share exports the current source to PDF.

## LaTeX

Open a project folder, select its main document and compile. Project settings control the engine, binary directory, editor theme, font size and history interval. Missing TeX tools open a compact installation guide.

Files and Outline fold independently. Rename files or the project inline. SyncTeX connects source lines and PDF locations. Cmd+/ toggles comments; Tab and Shift+Tab adjust source indentation.

Compile offers a fresh rebuild and a submission comparison. The comparison checks the current source and a bibliography-embedded variant in separate snapshots, with progress and logs for each result. Embed bibliography presents the source change for review. Remove notes (%) removes author comments while preserving captions and TeX directives.

History follows edits at the selected interval and coalesces small changes. Save, navigation and source tools preserve checkpoints. Tool changes carry Before/After markers. The recent-items menu can move local editing history to Trash.

## Local search and agents

Add folders to the local library and search their contents. Results retain document and page context. CLI agents can read buffers and compiler logs, apply fingerprint-checked edits and export results. The eye control colours session-only CLI edits. Source changes remain undoable; saving is explicit.
