# Read, write and find

Start with the work in front of you. Each workspace keeps the tools for that task nearby.

## PDF

Read, highlight, leave comments and arrange pages. [Read a paper →](workspace/pdf.md)

## Markdown

Write in source, read the formatted result, or keep both in view. [Write a note →](workspace/markdown.md)

## LaTeX

Keep source, project files and the compiled PDF together. [Open a project →](workspace/latex.md)

## Writer

Create a letter or short page document, then save as DOCX or PDF. [Begin a document →](writer.md)

## Search

Find matching passages across your own PDF and Markdown folders. [Find a passage →](workspace/search.md)

## Overleaf

Connect a project link with a Git token. Online synchronises saved source automatically. On-device keeps work local. Comments and suggestions connect separately. [Connect a project →](workspace/overleaf.md)
