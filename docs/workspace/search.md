# Search

Find the passage you remember, even when the filename has slipped away.

## Search your folders

1. Open Search from Home.
2. Add a PDF or Markdown folder to Library and let it index.
3. Enter a word or phrase and press Return.

Use quotation marks for an exact phrase. Results keep the page context beside the match. Open a result to continue reading, or choose **Save reference** to keep the paper in [Reference](../reference.md).

## Keep it current

Use Update Index after files change. The circle beside each folder opens its search coverage. An exclamation mark indicates files that could not be indexed or contain pages without searchable text. Open those PDFs and use Scan & OCR when needed.

Keyword results appear first. Apple Intelligence can then refine a natural-language question on a supported Mac. Standard search remains available offline and needs no AI account.

Use the arrows beside the result sort menu to browse further matches. Each page holds up to 200 matches. Sorting and document filters apply to the current page.

## Search the main text

Detected reference lists are left out by default. To search them too, enable **Include bibliography matches** in Settings → Search. Uncertain sections stay searchable.

Search recognises forms such as `H₂` / `H2`, `ε` / `epsilon` and typographic ligatures. Search can also join words split across PDF line breaks. Original documents are unchanged.

Search reuses its prepared index between launches.
