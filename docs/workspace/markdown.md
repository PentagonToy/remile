# Markdown

A small place for notes that can grow into something more.

## Begin writing

1. Open a Markdown file, or choose Markdown from Home.
2. Use **Edit** for source, **Read** for the formatted page, or **Split** for both.
3. Save your file. Use Share when you need a PDF.

## Add a little structure

The Format tools insert headings, links, lists, maths, code and tables. Pasting cells from a spreadsheet creates a table.

Keep local images beside the document or in a subfolder. Remote images use a local cache so revisiting a page can reuse downloaded images. The source's cache policy controls refreshes. Online access is required to load remote images. PDF export uses local images and supported formulae.

## Settle into the page

**Settings → Markdown** controls source size, spelling, line numbers and live preview. The editor’s settings show the same preferences. [Writing assistance](../assistant.md) is available when you want another look at a passage.
