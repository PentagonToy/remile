# Buttons and status

A small symbol can point the way. Hover over a button in remile to see its name. In narrow windows, extra controls may move into More (…).

## Keyboard access

In Markdown, Search and LaTeX workspaces, use **Workspace → Show or Hide Ask** (⇧⌘A) or **Reference Library…** (⇧⌘R). **Restore Panes** reveals collapsed split panes without resetting saved widths. LaTeX also offers **Show Logs or PDF**.

## When a button is grey

It is unavailable for the current selection or state. Select the document, text or object it needs, or wait for the current operation to finish. A provider-dependent button can also need a connection.

Guide icons are simplified drawings. The app uses native symbols, which can vary slightly with macOS.
