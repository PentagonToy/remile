# Guide symbols

`native-map.json` maps guide illustrations to the native SF Symbols used by remile. Toolbar symbols use regular weight, medium scale and monochrome ink. Selected modes and status marks have their own colours.

The SVGs are original simplified guide illustrations under the project MIT licence. They describe the same actions without redistributing Apple artwork. `../system-symbols.json` inventories native symbols in the source. Keep both mappings current when changing a control.
